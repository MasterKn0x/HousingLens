Nevertheless, to the average consumer or investor, it is quite difficult to have the real and clear valuation of property. The conventional techniques of property valuation tend to be baseless or mere comparisons that cannot consider the complicated, non–linear connections amid the characteristics and the market worth of a property. With the introduction of Machine Learning (ML), there is a new technology called Automated Valuation Models (AVMs) that is expected to be more accurate. However, even these high-tech tools tend to be black-boxes and only offer one price value without the confidence level or the risk behind such an estimate. The project is named HousingLens and it is working within this context of growing availability of data and still having the lack of transparency in risk evaluation.1.2 Problem StatementThere is a major gap in the existing tools in the real estate market. Other systems that are currently present in the market as online house valuation systems are often single and deterministic in their price. This solution is dangerous to both the buyers and the investors, since it does not give any idea in the volatility of the market or the accuracy (or inaccuracy) of the prediction made. Such lack of transparency may result in making poor decisions and having little to no idea of the actual market volatility of an asset. HousingLens is designed to fill this particular informational gap by proposed Investment Risk Index (IRI) with price prediction based on statistical principals.1.3 Project Aims and Objectives1.3.1 AimThe project aims to create, design and test a machine learning model to be able to forecast the worth of residential properties with a high degree of precision and offer a viable appraisal of the risk of the investment.To source, clean and prepare an exhaustive list of property sales, which can be used in statistical modelling. The purpose of the study is to build and optimize a set of machine learning regression models with the goal of finding the best predictor.To generate new geospatial and density features in order to increase predictability of the information.To apply the chosen model in the shape of interactive HousingLens Dashboard in the context of the risk and prices prediction in real-time.1.4 Structure of the contextual report.This report has been divided into 4 chapters.Chapter 1 (Introduction) : Provides the background of the project, problem statement, aims and objectives as stated in the approved proposal.Chapter 2 (Literature Review) : This is the main research part. This theory of economics holds that price of a complex good is never set as a whole, but rather a process of constituent characteristics. In the case of a residency property, the price is sum of,Structural Attributes : The characteristics of the structure such as square feet, bedrooms, and age of the building.Locational (Geospatial) Attributes : Deliberate, external influences including access to schools, transport connections, parks and access to noise or crime in the neighborhood.The conventional statistical techniques applied a linear regression to model this relationship. Nevertheless, such non-linear relationships among these features (e.g – The price of an additional bedroom would not be the same in an urban centre as in the countryside) resulted in the superiority of machine learning that can automatically model these complex relationships. The hypothesis underpinning this project is that with the development of better geospatial features (Objective 3), the correct model of the actual hedonic value can be developed.2.2 State of the Art Systems ReviewThe analysis of the existing field shown that there are many systems available with Automated Valuation Models (AVMs). This economic theory posits that the price of a complex good is not determined as a whole, but is rather a function of its constituent characteristics. For a residential property, the price is an aggregate of:Structural Attributes: Tangible features like square footage, number of bedrooms, and age of the building.Locational (Geospatial) Attributes: Intangible, external factors such as proximity to schools, transport links, parks, and levels of neighbourhood noise or crime.Traditional statistical methods used linear regression to model this relationship. However, the complex, non-linear interactions between these attributes (e.g., the value of an extra bedroom is different in a city centre versus a rural area) have led to the dominance of machine learning, which can model these intricate relationships automatically. This project is predicated on the hypothesis that by creating superior geospatial features (Objective 3), a more accurate model of the true hedonic value can be constructed.2.3 Review of State-of-the-Art SystemsA review of the current domain reveals numerous systems offering Automated Valuation Models (AVMs). It proves the "design" of the model is statistically sound.K-Fold Cross-Validation: The dataset will be split into 'k' folds (e.g., k=10). The model will be trained 10 times, each time holding out a different 10% of the data for testing. This ensures the model's performance is stable.$R^2$ (R-squared): This metric (0-1) will be used to measure how much of the price variation the model can explain. An $R^2$ of 0.85 means the model explains 85% of the price variance. This is the primary metric for success (NFR3).RMSE (Root Mean Squared Error): This metric will be used to measure the average error in LKR. An RMSE of 500,000 LKR means the model is, on average, off by that amount. This is a measure of accuracy.MAE (Mean Absolute Error): Similar to RMSE, but less sensitive to large outliers.4.4.2 Software Artefact Testing (Validating the Implementation)This validates the Streamlit app (the software).Unit Testing (pytest): Individual Python functions (e.g., calculate_iri(), clean_data()) will be tested in isolation.Integration Testing: The full application will be tested to ensure the UI sliders correctly pass data to the backend model and that the model's output is correctly displayed.User Acceptance Testing (UAT): A small group of non-technical users will be asked to use the dashboard and provide feedback on its usability (NFR2).4.5 Evaluation PlanThe final project will be evaluated against the Aims and Objectives (Section 1.2).Objective 1 & 3 (Data): Success is a final, cleaned, feature-engineered dataset.Objective 2 (Model): Success is a final, trained model that meets the reliability target (NFR3, $R^2$ > 0.85) and outperforms the baseline.Objective 4 (Artefact): Success is a deployed, functional HousingLens dashboard that passes all tests defined in Section 4.4.2 and satisfies all Functional Requirements (Section 4.2.1).References(This list is populated from your approved Project Proposal and expanded to include key theoretical texts)Géron, A. The conventional techniques of property valuation tend to be baseless or mere comparisons that cannot consider the complicated, non-linear connections amid the characteristics and the market worth of a property. With the introduction of Machine Learning (ML), there is a new technology called Automated Valuation Models (AVMs) that is expected to be more accurate. However, even these high-tech tools tend to be black-boxes and only offer one price value without the confidence level or the risk behind such an estimate. The project is named HousingLens and it is working within this context of growing availability of data and still having the lack of transparency in risk evaluation.1.2 Problem StatementThere is a major gap in the existing tools in the real estate market. Other systems that are currently present in the market as online house valuation systems are often single and deterministic in their price. This solution is dangerous to both the buyers and the investors, since it does not give any idea on the volatility of the market or the accuracy (or inaccuracy) of the prediction made. Such lack of transparency may result in making poor decisions and having little to no idea of the actual market volatility of an asset. HousingLens is designed to fill this particular informational gap by proposed Investment Risk Index (IRI) with price prediction based on statistical principles.1.3 Project Aims and Objectives1.3.1 AimThe project aims to create, design, and test a machine learning model to be able to forecast the worth of residential properties with a high degree of precision and offer a viable appraisal of the risk of the investment.1.3.2 ObjectivesTo source, clean and prepare an exhaustive list of property sales, which can be used in statistical modelling.The purpose of the study is to build and optimize a set of machine learning regression models with the goal of finding the best predictor.To generate new geospatial and density features in order to increase predictability of the information.To apply the chosen model in the shape of an interactive HousingLens Dashboard in the context of the risk and prices prediction in real-time.1.4 Structure of the contextual report.To meet the CIS013-3 Assignment 2 brief, this report has been divided into four chapters.Chapter 1 (Introduction): Provides the background of the project, problem statement, aims and objectives as stated in the approved proposal.Chapter 2 (Literature Review): This is the main research part and it is worth half of the total mark. Last, but not least, this analysis concludes with the identification of a specific research gap, which justifies the original nature of the project HousingLens.2.2 Hedonic Pricing Models Theoretical Framework.Hedonic Pricing Model is the basis of all contemporary property valuation, even AI-powered models (Rosen, 1974). This theory of economics holds that price of a complex good is never set as a whole, but rather a process of constituent characteristics. In the case of a residential property, the price is a sum of:Structural Attributes: The characteristics of the structure such as square feet, bedrooms, and the age of the building.Locational (Geospatial) Attributes: Deliberate, external influences including access to schools, transport connections, parks and access to noise or crime in the neighbourhood.The conventional statistical techniques applied a linear regression to model this relationship. Nevertheless, such non-linear relationships among these features (e.g., the price of an additional bedroom would not be the same in an urban centre as in the countryside) resulted in the superiority of machine learning that can automatically model these complex relationships. The hypothesis underpinning this project is that with the development of better geospatial features (Objective 3), the correct model of the actual hedonic value can be developed.2.3 State-of-the-Art Systems Review.The analysis of the existing field has shown that there are many systems available with Automated Valuation Models (AVMs). They, however, are mostly competing on the quality of their price estimate, rather than the disclosure of its risk. This comparison analysis presents the functional constraints of the existing tools.State-of-the-Art Gap: The AVMs currently in the market are black box models that present the uncertainty in their model to the user, placing them at risk. Local Sri Lankan marketplaces (ikman.lk) do not predict in any way.Scholarly Gap: Although most papers (e.g., Niu, et al., 2023) discuss the comparison of model accuracy, few of them suggest a methodology of translating model uncertainty (e.g., a prediction variance) into a simple, actionable and user-friendly measure.To bridge these gaps, HousingLens itself will provide a solution to the current opportunity in an easy-to-use tool that is based on a new statistical deliverable, the Investment Risk Index (IRI), to address the gap in academic literature and offer transparency where the current tools do not.Chapter 3: Project Plan(This chapter deals with the 20% "Project plan, with GANTT chart" aspect)3.1 IntroductionProper project plan would help in ensuring the project is accomplished within the academic schedule.
